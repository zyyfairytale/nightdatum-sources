Night Datum

Privacy policy

Last updated 26 September 2026

Night Datum is an independent, one-person YouTube channel. "Night Datum tools" is a private tool used only by the channel's owner to publish and manage videos on the Night Datum YouTube channel.

What the tool accesses

With the owner's permission, the tool uses the YouTube Data API and YouTube Analytics API to upload videos, set their titles, descriptions, captions and thumbnails, and read the channel's own performance statistics (such as views and audience retention).

Whose data

The tool is used only with the owner's own Google account and the Night Datum channel. It does not collect, store or process personal data of viewers or any other person.

Storage and sharing

The access token is stored on the owner's own computer. Analytics figures are used only to improve future videos. Nothing is sold or shared with third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: open an issue at github.com/zyyfairytale/nightdatum-sources/issues.
